# 볼트노트

기계엔지니어가 혼자 운영하는 체결부품 공급·엔지니어링 견적 사이트입니다.

- **BOM 붙여넣기 견적 (4A장)**: 엑셀·CSV·텍스트 BOM을 붙여넣으면 줄마다 나사·강도·표면처리·규격을 읽어 품번, 예시 단가, 포장 조합, 납기 단계, 서류 계획, 도면을 붙입니다. 판단이 필요한 줄만 확인 목록에 남고, 공급하지 않는 줄은 Not available로 따로 모읍니다.
- **견적서·C&D 문서 (4A-1장)**: 공공기관 양식 필드가 있는 견적서, Clarification & Deviation 시트(기술·상업 분리), 준수 요약, 공급 불가 목록, 도면 묶음, 가격 없는 기술본, 개정 비교. 엑셀(5시트)·JSON·CSV로 내보냅니다.
- **API 610 재질 클래스 → 볼팅 (5장 도구)**: 판(edition)별 스터드·너트 재질을 나란히 보여 주고, 판이 불분명하면 차이를 표시합니다.
- **미터 규격품**: KS·ISO·DIN·JIS 8개 품목(육각볼트, 렌치볼트, 접시머리, 너트, 와셔, 전산볼트). 형번 선택기, 수량별 예시 단가, 출고일을 보여 줍니다.
- **인치·플랜트 볼트 견적**: ASME·ASTM·SAE 품목(A193 B7/B7M/B8, A320 L7, A194 너트, F3125 A325/A490, SAE J429, A574, F593, F1554 등). 사양을 고르면 견적함에 담깁니다.
- **주문제작·해외규격 견적**: 나사, 치수, 재질, 표면처리, 서류를 항목별로 받습니다. 입력하는 동안 엔지니어 점검 항목(빠진 정보, 수소취성, 짝 너트 등)을 함께 보여 줍니다.
- **규격 도구**: B16.5 플랜지 스터드 길이, 규격·재질·강도 대조표, DIN·ISO 2면폭 차이, 인치↔mm, 머리 마킹.
- **사양 표기 해석기**: `1/2-13 UNC-2A x 3-1/2" A193 B7` 같은 한 줄 표기를 항목별로 풀어 줍니다.

## 파일

| 경로 | 내용 |
|---|---|
| `site/page.html` | 사이트 원본. 한 파일로 된 웹앱(HTML·CSS·JS)이며 글꼴만 Google Fonts에서 불러옵니다. |
| `site/build.py` | `page.html`을 완전한 HTML 문서로 감싸 `docs/index.html`을 만듭니다. |
| `docs/index.html` | 배포본. 직접 고치지 말고 `python3 site/build.py`로 다시 만듭니다. |
| `docs/_headers` | 응답 헤더(보안 헤더, 캐시) |
| `wrangler.jsonc` | Cloudflare Workers 배포 설정 (`docs/`만 공개) |
| `docs/robots.txt` | 검색 로봇 허용 |

## 배포

Cloudflare Workers(정적 파일, 무료)가 `main` 브랜치의 `docs/` 폴더를 배포합니다. 설정은 `wrangler.jsonc`에 있습니다.

| 설정 (Cloudflare 대시보드 → Worker `boltnote` → Settings → Build) | 값 |
|---|---|
| Git 저장소 | `LongmanMacrolenz/dollar-design` |
| 프로덕션 브랜치 | `main` |
| 빌드 명령 | `exit 0` |
| 배포 명령 | `npx wrangler deploy` |
| 미리보기 빌드 | 쓰지 않음. 이 저장소에서는 PR 미리보기 빌드가 실패하지만 공개 배포에는 영향이 없습니다. 공개 배포는 main 빌드만 사용합니다. |

`wrangler.jsonc`의 `name`은 대시보드의 Worker 이름과 같아야 합니다. `docs/_headers`의 보안·캐시 헤더도 함께 적용됩니다.

GitHub Pages는 약관상 온라인 사업·전자상거래 사이트에 쓸 수 없으므로 게시를 끕니다.

- 가격, 재고, 출고일은 무게 기반의 예시 계산입니다. 실제 매입가와 재고로 바꿔야 합니다.
- 견적 요청은 사이트가 요청서 파일을 만들고 고객이 메일·카카오톡으로 보내는 방식입니다. 연락처 자리표시를 실제 주소로 바꿔야 합니다.
