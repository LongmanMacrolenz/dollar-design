# 볼트노트

기계엔지니어가 혼자 운영하는 체결부품 공급·엔지니어링 견적 사이트입니다.

- **미터 규격품**: KS·ISO·DIN·JIS 8개 품목(육각볼트, 렌치볼트, 접시머리, 너트, 와셔, 전산볼트). 형번 선택기, 수량별 예시 단가, 출고일을 보여 줍니다.
- **인치·플랜트 볼트 견적**: ASME·ASTM·SAE 품목(A193 B7/B7M/B8, A320 L7, A194 너트, F3125 A325/A490, SAE J429, A574, F593, F1554 등). 사양을 고르면 견적함에 담깁니다.
- **주문제작·해외규격 견적**: 나사, 치수, 재질, 표면처리, 서류를 항목별로 받습니다. 입력하는 동안 엔지니어 점검 항목(빠진 정보, 수소취성, 짝 너트 등)을 함께 보여 줍니다.
- **규격 도구**: B16.5 플랜지 스터드 길이, 규격·재질·강도 대조표, DIN·ISO 2면폭 차이, 인치↔mm, 머리 마킹.
- **사양 표기 해석기**: `1/2-13 UNC-2A x 3-1/2" A193 B7` 같은 한 줄 표기를 항목별로 풀어 줍니다.

## 파일

| 경로 | 내용 |
|---|---|
| `site/page.html` | 사이트 원본. 한 파일로 된 웹앱(HTML·CSS·JS)이며 글꼴만 Google Fonts에서 불러옵니다. |
| `site/build.py` | `page.html`을 완전한 HTML 문서로 감싸 `docs/index.html`을 만듭니다. |
| `docs/index.html` | 배포본. 직접 고치지 말고 `python3 site/build.py`로 다시 만듭니다. |
| `docs/_headers` | Cloudflare Pages 응답 헤더(보안 헤더, 캐시) |

## 배포

Cloudflare Pages(무료)가 `main` 브랜치의 `docs/` 폴더를 배포합니다.

| 설정 | 값 |
|---|---|
| 프로덕션 브랜치 | `main` |
| 프레임워크 프리셋 | 없음 |
| 빌드 명령 | `exit 0` |
| 빌드 출력 디렉터리 | `docs` |
| 미리보기 배포 | 끔 (작업 중인 브랜치가 공개되지 않게) |

GitHub Pages는 약관상 온라인 사업·전자상거래 사이트에 쓸 수 없으므로, Cloudflare Pages가 공개되면 저장소 Settings → Pages에서 게시를 끕니다.

## 공개 전에 바꿔야 할 것

- 푸터의 사업자 정보(대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 전화, 이메일, 개인정보 보호책임자)는 노란색 자리표시입니다. 전자상거래법상 표시 의무 항목이므로 실제 정보로 바꿔야 합니다.
- 가격, 재고, 출고일은 무게 기반의 예시 계산입니다. 실제 매입가와 재고로 바꿔야 합니다.
- 견적 요청은 사이트가 요청서 파일을 만들고 고객이 메일·카카오톡으로 보내는 방식입니다. 연락처 자리표시를 실제 주소로 바꿔야 합니다.
