# 볼트노트 (가칭)

기계엔지니어가 혼자 운영하는 체결부품 온라인 쇼핑몰의 홈페이지 초안입니다.

- **미터 규격품 즉시 주문**: KS·ISO·DIN·JIS 8개 품목(육각볼트, 렌치볼트, 접시머리, 너트, 와셔, 전산볼트). 형번 선택기, 수량별 단가, 14시 마감 출고일을 보여 줍니다.
- **인치·플랜트 볼트 견적**: ASME·ASTM·SAE 10개 품목(A193 B7/B7M/B8, A320 L7, A194 너트, F3125 A325/A490, SAE J429, A574, F593, F1554). 사양을 고르면 견적함에 담깁니다.
- **주문제작·해외규격 견적**: 나사, 치수, 재질, 표면처리, 서류(EN 10204 3.1 등)를 항목별로 받습니다. 입력하는 동안 엔지니어 점검 항목(빠진 정보, 수소취성, 짝 너트 등)을 함께 보여 줍니다.
- **규격 도구**: B16.5 플랜지 스터드 길이, 규격·재질·강도 대조표, DIN·ISO 2면폭 차이, 인치↔mm, 머리 마킹.
- **사양 표기 해석기**: `1/2-13 UNC-2A x 3-1/2" A193 B7` 같은 한 줄 표기를 항목별로 풀어 줍니다.

벤치마킹 대상은 Grainger(검색·카테고리·스펙 표), MISUMI(형번 선택, 수량별 단가, 출고일), 화신볼트(주문제작 사양 입력)입니다.

## 파일

| 경로 | 내용 |
|---|---|
| `site/page.html` | 사이트 원본. 한 파일로 된 웹앱(HTML·CSS·JS)이며 글꼴만 Google Fonts에서 불러옵니다. |
| `site/build.py` | `page.html`을 완전한 HTML 문서로 감싸 `docs/index.html`을 만듭니다. |
| `docs/index.html` | GitHub Pages 배포본. 직접 고치지 말고 `python3 site/build.py`로 다시 만듭니다. |

## 배포

GitHub 저장소 Settings → Pages에서 **Deploy from a branch**, 브랜치 `main`, 폴더 `/docs`를 고르면 `docs/index.html`이 공개됩니다.

## 공개 전에 바꿔야 할 것

- 푸터의 사업자 정보(상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 전화, 이메일, 개인정보 보호책임자)는 노란색 자리표시입니다. 전자상거래법상 표시 의무 항목이므로 실제 정보로 바꿔야 합니다.
- 가격, 재고, 출고일은 무게 기반의 예시 계산입니다. 실제 매입가와 재고로 바꿔야 합니다.
- 주문·결제와 견적 접수는 화면 데모입니다. 실제 운영에는 결제대행(PG)과 견적 접수 메일 또는 폼 서비스를 연결해야 합니다.
