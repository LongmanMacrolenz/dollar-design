# 첫 화면 회사 소개

첫 화면은 조달 업무를 소개하며, 재생이나 장면 선택을 요구하지 않는다. ‘체결부품 조달, BOM부터 정확하게’와 회사 설명, BOM 견적 요청·특수요건 확인은 항상 표시한다. 16초 무음 영상의 네 장면마다 BOM 검토·특수요건·공급 확인·견적과 C&D 메시지와 구체적인 검토 예시가 이어진다. 제조·시험·재고 보유를 주장하지 않는다.

`tools/render_sourcing_film.py`는 독자 제작한 스터드·너트·와셔와 UNF 후보의 384개 형상/카메라 상태를 Cycles로 새로 렌더링한다. 제품 전체 → 외부/내부 나사 확대 → 후보 대조 → 전체 구도로 이동하며, 부품의 축 방향 분리와 카메라 이동을 함께 사용한다. OIDN으로 프레임별 노이즈를 제거하고 `tools/encode_brand_film.py`로 960×600 및 640×400 모바일 MP4를 만든다. 24fps, 소리 없음, faststart이며 나사산 사이의 광학 흐름 합성을 사용하지 않는다. 새 파일명 `boltnote-sourcing*`으로 이전 캐시와 구분한다.

2D는 `v7_sourcing_drawing.js`의 독자 벡터 도면으로 스터드 측면·끝면, 헤비너트 정면·단면, 외부/내부 나사의 선 굵기, 중심선, 치수선, 단면 해칭을 구분한다. 길이 L·너트 s/m은 기호만 쓰며 제조 치수로 숫자를 만들지 않는다. ‘3/4″–10 UNC–2A’, ‘UNC–2B’, UNC 10 TPI/UNF 16 TPI, A193 B7 요청 표기는 기존 `site/lib.json`의 `t-unc-unf`, `t-inch-class`, `astm-a193`에서 재사용한다. 너트의 3D 비례는 기존 `precision_geometry.py`의 공개 RCSC 헤비너트 호칭 예이며 ASME 치수 승인이나 공차 충족 모델이 아니다.

예시는 실제 고객 BOM·공급 회신이 아니다. 요청 표기와 추가 확인 항목, ‘UNC 요청 ↔ UNF 후보 = 나사 계열 불일치’, 견적과 C&D의 구성만 보여준다. 나사 표기만 같은 후보를 전체 요건 준수로 승인하지 않는다. 단가·납기·서류 제공 여부를 만들어 넣지 않는다. 3D 부품에 붙이는 표기는 실제 카메라에서 투영한 위치를 사용한다.상세 뷰어의 처음 6초도 새 영상으로 교체해 거친 평면/와이어 형상을 없앴다. 6초 이후의 나사 공차·재료·시험·표면처리 장면은 원본의 시간과 해석을 유지한다.

재현: `blender -b -t 5 --python-exit-code 1 -P tools/render_sourcing_film.py -- --out /tmp/raw --track /tmp/track.json --width 960 --samples 6`, `python3 tools/denoise_hero.py /tmp/raw /tmp/clean --oidn /path/to/oidnDenoise`, `python3 tools/encode_brand_film.py /tmp/clean --track /tmp/track.json`, `python3 tools/build_all.py`.

`v7_brand.js`는 뷰포트 진입 시 해당 화면 크기의 파일만 연결하고 `muted`·`playsinline`으로 재생한다. 문구·진행 상태·도면에서 입체로의 전환·부품 표기는 디코딩된 영상 시간에 따른다. 일시정지는 영상과 문구를 함께 멈춘다. 화면 밖·숨겨진 탭에서 멈추고 돌아오면 이어진다. 경로 변경은 옵저버·리스너·프레임 콜백·미디어를 정리한다. 기술 뷰어를 열면 소개를 멈춰 두 영상이 경쟁하지 않는다.

움직임 줄이기 또는 데이터 절약 설정에서는 첫 미디어 다운로드 없이 포스터·회사 설명·견적 버튼을 보여준다. 자동 재생이 브라우저 정책이나 통신 상태로 제한되어도 회사 설명은 사라지지 않는다. 이때만 사용자가 원하면 작은 ‘소개 계속 보기’로 시작할 수 있다. 자동 문구 전환을 스크린 리더에 반복 알리지 않는다.
