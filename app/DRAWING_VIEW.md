# 2D 도면과 통합 영상 뷰어

첫 화면은 자동 재생되는 16초 회사 소개와 BOM 견적 요청으로 구성한다. 회사의 사양 검토·조달 역할은 영상이 재생되기 전부터 표시한다. 공차·재료·시험 설명은 ‘더 깊이 보는 체결부품’에서 펼쳐본다. 이 상세 뷰어는 데스크톱에서 영상과 해설을 나란히, 모바일에서 하나의 카드에 배치한다. 긴 적용 조건은 카드 안에서 열고 읽는다. 상세 뷰어의 2D 형상 버튼은 영상 파일을 받지 않고 독자적으로 작성한 벡터 형상도를 보여준다. 상세 영상 첫 장면에도 벡터 도면을 겹쳐 표시하고 입체 장면으로 전환한다. SVG 도면은 형상 참고도이며 제작 승인 도면이 아니다.

`v9_drafting.js`는 기존 미터 `DIM`, 공개 근거가 있는 인치 헤비너트 `hhnIn`, 신규 품목의 원문 대조 `IA_DRAW` 값과 사용자 선택 길이만 치수 문자에 쓴다. 빈 치수는 그리지 않는다. 그림 비례는 NTS이며 긴 몸체는 축약선으로 구분한다. 일부 치수가 없을 때 형태를 설명하는 비례는 수치로 내보내지 않는다. 치수표의 인치 분수는 원래 표기를 유지한다. 접시머리 길이는 머리 포함, 그 밖의 볼트는 좌면 아래 기준이다.

도면은 외형·가는 면선·중심선·숨은선·치수선을 구분한다. 나사는 가는 골지름 선으로 표현한다. 모바일에서는 실제 SVG의 치수 문자를 별도 칩으로 읽을 수 있고, 확대와 SVG 저장은 동일 도면을 사용한다. SVG 저장 시 계산된 스타일을 포함해 외부 CSS 없이 열 수 있다. 기존 3D/2D 탭과 CAD 치수 데이터는 유지한다.

시험 도해는 재료 원리를 설명한다. S–N 개념 곡선을 제품별 측정곡선으로 표시하지 않으며, 자료를 지어내지 않는다. ‘준비 중’과 빈 납기 범위 같은 표현을 제공 범위·도면 기반 검토·공급처 확인 절차로 바꾼다. 공개 제공 범위와 미확인 조건은 계속 명시한다.
