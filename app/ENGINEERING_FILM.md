# 체결부품 상세 뷰어의 규격·재료 영상

42초 · 24 fps · 1008개 원본 형상 상태. 2D→3D, UNC/UNF, 헤비너트, 탄성 인장, 반복하중, 별도 시편 경도, 표면처리의 7장면입니다. 홈의 ‘더 깊이 보는 체결부품’에서 선택해서 보며, 첫 화면의 자동 회사 소개는 이 원본을 16초로 편집한 별도 영상입니다(`COMPANY_INTRO.md`). `tools/render_material_film.py`는 기존 원본 스튜디오의 직접 생성한 메시·PBR 조명을 재사용합니다. 원격 플레이어·광고·3D 런타임을 사용하지 않습니다.

## 근거와 표현의 경계

- 인치 3/4″-10 UNC 및 3/4″-16 UNF 산 수: 검토된 `site/lib.json`의 `t-unc-unf` (NIST H28·ISO 2306·ASME B1.1). 60° 기본 산형은 기존 `precision_geometry.py`. 제작 공차나 골 반경 검증 모델이 아닙니다.
- 1A/2A/3A 및 1B/2B/3B, 1A·2A의 같은 여유/3A 여유 없음: `t-inch-class` (NIST H28·ASME B1.1). SVG 공차대 폭·틈은 확대 개념도이며 실제 한계치·비율을 나타내지 않습니다. 일반 UN 나사 클래스 C를 만들어내지 않습니다.
- 도금 전 3/4″-10 UNC-2A 외경 상한 0.7482″, 기본 0.7500″, 차이 0.0018″=45.72 µm: 기존 `t-inch-class`의 승인된 예(NIST H28·ASME B1.1). 유효지름 공차대 폭이나 전체 제조 공차와 혼동하지 않도록 표시합니다. 3D는 기본 형상이며 실제 제조 상한을 확대해 재현한 모델이 아닙니다.
- 헤비너트 3/4″ 호칭 높이 소수 표기 0.734″(약 18.64 mm), 2면폭 1-1/4″: 기존 `HHN_IN`·`HEAVY34`·`t-heavy-hex`, RCSC 2025 표 C-2.1. 구조용 호칭 예이며 높이 최소/최대가 아닙니다. 일반 육각의 높이는 도식용으로 치수값·증가비를 제시하지 않습니다. 플랜트 ASME B18.2.2 치수 승인으로 간주하지 않습니다.
- 8.8 공칭 인장 800 MPa, 10.9 공칭 인장 1000 MPa: 기존 `pc-steel`·`t-yield-tensile`(ISO 898-1)의 강도 구분 해석. A4-80 최소 인장 800 MPa: `pc-a2-a4`·`t-yield-tensile`(ISO 3506-1). 공칭과 최소의 서로 다른 기준을 화면에 표시합니다. 실물 시험 결과·탄성한도·응력-변형률 곡선으로 바꾸어 쓰지 않습니다.
- 탄성 장면: 단위 없는 하중/과장된 변형을 사용하고 장면 종료 전에 원래 위치·형상으로 복귀합니다. 항복·파단·균열을 표현하지 않습니다. 0.2% 내력을 완전 탄성한도로 취급하지 않습니다. 강도가 높은 등급을 더 높은 탄성계수로 표현하지 않습니다.
- 반복하중: 실제 S–N 자료가 없는 상태에서 등급별 피로곡선·피로한도·수명을 만들지 않습니다. 점선 개념도와 제한된 반복 인장을 표현합니다. 탄성 범위의 반복하중도 피로를 일으킬 수 있음을 표시합니다. `t-fatigue`(NASA RP-1228·ISO 3800)와 연결합니다.
- 경도: `t-hardness`의 시험 원리. 실제 경도는 국부 영구 압흔으로 측정하므로 별도 시편을 사용하고 압흔을 유지합니다. 완성 볼트가 경도 압입 뒤 탄성 복귀한 것처럼 표현하지 않습니다. 척도·시험력·결과 숫자는 생성하지 않습니다.
- 코팅: 색상은 보호층의 시각적 구분이며 재료 식별 또는 성능 등급이 아닙니다. 세 색에 같은 보호층 표현을 적용합니다. 무코팅 기재/보호층 결함과 건조·습윤·염분의 원리를 보여주며 실제 부식률·염수분무 시간·옥외 수명을 예측하지 않습니다. 아연 백청과 기재 적청을 구분하며 영상의 갈색은 기재 부식 도식입니다. PTFE계, 아연계, 흑착색+방청유는 가능한 예일 뿐 색상만으로 확정하지 않습니다. 기존 `t-black-oxide`, `t-hdg`, `t-zinc-plating`, `t-zinc-flake`, `t-ptfe`, `t-salt-spray` 항목의 구매 확인 범위를 사용합니다.

이번 작업은 규격 숫자표를 새로 추가하거나 유료 PDF·규격 전문·외부 도면을 복제하지 않습니다. 기존 사전의 검토된 숫자와 정성 원리를 재사용했습니다. 공칭 형상 및 강도 구분을 합부 판정·설계 계산에 사용하지 않습니다.

## 재현

```bash
blender -b -t 4 --python-exit-code 1 -P tools/render_material_film.py -- --out /tmp/boltnote-material-raw --width 1200 --samples 2
python3 tools/denoise_hero.py /tmp/boltnote-material-raw /tmp/boltnote-material-clean --oidn /path/to/oidnDenoise
python3 tools/encode_material_film.py /tmp/boltnote-material-clean
python3 tools/build_all.py
python3 tools/check.py
```

모든 프레임은 직접 렌더링한 상태 또는 완전히 같은 상태의 복사본입니다. 광학 흐름으로 나사산을 합성하지 않습니다. 정지 상태를 정확히 재사용하고 OIDN은 프레임별 공간 노이즈만 제거합니다. 기존 조립 영상과 적용 카드 이미지는 유지합니다. 새 파일 이름으로 배포하여 이전 캐시와 섞이지 않게 합니다.
