# 규격 사전 항목 명세

규격 사전(`#lib`, 정적 페이지 `docs/lib/`)의 원본은 `site/lib.json`(항목 배열)입니다.
고치는 순서: `site/lib.json` 수정 → `python3 tools/sync_lib.py`(검사 + `app/src/ea_lib.js` 생성) → `python3 tools/build_all.py` → `python3 tools/check.py`.

독자는 플랜트·정비·구매·설계 엔지니어입니다. 숫자 하나가 틀리면 열 개를 빠뜨린 것보다 손해가 큽니다.

## 지식 지도와 읽기 경로

`site/lib-guide.json`은 주제 분류(`topics`)와 목적별 읽기 순서(`paths`)의 편집 원본입니다.
주제마다 `id, title, en, desc, featured, entries`를 적습니다. 모든 사전 항목은 정확히 한 주제에 속하고, 추천 항목(`featured`)도 그 주제 안에 있어야 합니다.
읽기 경로는 `id, title, audience, desc, steps`를 적고, 각 단계는 `title, desc, entries`로 기존 항목을 연결합니다. 수치·요건은 이 파일에 추가하지 않습니다.
`tools/sync_lib.py`가 연결·분류 누락을 검사하고 `app/src/ea_lib_guide.js`를 생성합니다. 정적 페이지도 같은 원본을 읽습니다.
지도를 고친 뒤에도 `sync_lib.py` → `build_all.py` → `check.py` 순서를 지킵니다.
검색·주제·읽기 경로는 `/#lib?q=…&topic=…&path=…&kind=…&org=…`로 공유할 수 있습니다. 항목 공유 주소는 `/lib/<id>`입니다.

## 규칙

1. **정확성이 먼저.** 확실한 값만 씁니다. 모르면 빼고, 대표에게 묻습니다. 규격 번호·판·경도·강도·온도를 추측하지 않습니다.
2. **출처 규칙을 지킵니다**: [`SOURCE_RULE.md`](SOURCE_RULE.md). 근거는 `src`에 규격 번호로 적습니다. T2(제조·유통사 3곳 일치)로만 확인한 항목은 `src`에 `제조·유통사 공개 기술자료 3곳 이상 대조 (규격서 원문 대조 전)`을 넣습니다.
3. **규격 원문을 옮기지 않습니다.** 사실·숫자·규격 번호를 우리 말로. 영어 정식 표제는 괜찮습니다.
4. **판은 꼭 필요할 때만.** "현행판"을 기본으로 하고, 폐지·대체는 `status`에 적습니다.
5. **상업적 약속을 쓰지 않습니다.** 재고·공급·보증·인증·시험 서비스, 가격, 납기, 회사·경쟁사·제조사 이름. 사용자가 검색할 상표(Xylan, Helicoil, Geomet 등)는 "(상표)"를 붙여 허용합니다.
6. **한국어, 짧고 담백하게.** 규격 표기는 그대로(`A193 B7`, `3/4"-10 UNC-2A`, `M16×2-6g`). 단위는 SI 먼저, 인치 규격이면 괄호에 ksi(`860 MPa (125 ksi)`). 환산한 값은 `환산`을 붙입니다. 영하는 `−`(`−101 °C`).
7. **BOM을 읽을 때 쓸모 있게.** `watch`에 흔한 함정을 적습니다(섞이는 동급 규격, 빠진 너트 등급, 용융아연도금 오버탭, B7M 경도, DIN과 ISO 2면폭 차이, 폐지된 규격이 도면에 남은 경우).
8. **다른 항목·사이트와 어긋나지 않게.** 같은 값이 다른 항목에도 있으면 함께 고칩니다. 용어: 2면폭, 용융아연도금, 지연파괴, 체결부품, MPa(N/mm² 아님), 보증응력.

## 항목 모양 (JSON 객체)

```
{
  "id": "astm-a193",                  // 겹치지 않는 영문 id (소문자·숫자·-)
  "t": "ASTM A193/A193M",             // 제목 (규격 번호 또는 용어)
  "ko": "…",                          // 한국어 이름, 40자 이하
  "en": "…",                          // 영어 정식 이름 (선택)
  "kind": "std|grade|mat|thread|concept|doc|test|coat|part",
  "org": "ASTM|ASME|ISO|EN|DIN|KS|JIS|SAE|API|NACE|-",
  "aka": ["A193", "SA-193"],          // 검색 별칭: 다른 표기, 현장 용어 (2개 이상)
  "sum": "한두 문장 요약, 160자 이하",
  "facts": ["핵심 사실 3~8개, 한 줄씩"],
  "table": {"cap": "표 제목", "head": ["열1","열2"], "rows": [["…","…"]], "note": "출처·조건"},   // 선택, 12줄 이하, 모든 칸이 확인된 값
  "watch": ["실무 주의 1~5개"],
  "eq": [{"std": "ISO 4017", "note": "치수 일부 다름"}],     // 선택: 동급·전신·후속 규격. "동일"은 근거 문장이 있을 때만, 아니면 "대응"
  "status": "현행 | 폐지 (→ …) | 대체 (→ …)",              // 선택
  "rel": ["astm-a194"],               // 관련 항목 id (lib.json에 있는 id만)
  "fam": ["b7"],                      // 관련 카탈로그 품목군 id (선택). 이름(famko)은 sync_lib.py가 채웁니다
  "src": ["ASTM A193/A193M"]          // 근거: 규격 번호 위주
}
```

- 필수: `id, t, ko, kind, org, sum, facts, src`. 권장: `aka` 2개 이상, `rel` 2개 이상.
- `facts`가 3줄 미만이 되거나 핵심 주장을 확인할 수 없으면 항목을 싣지 않는 편이 낫습니다.
- `famko`는 자동으로 채워집니다. 새 `fam` id를 쓰려면 같은 id의 이름이 이미 어떤 항목의 `famko`에 있어야 합니다.
- 항목 순서가 이전·다음 이동 순서입니다.
