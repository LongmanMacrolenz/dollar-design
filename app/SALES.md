# Sales 견적 문의

대표 결정 2026-10-06: 견적 요청의 기본은 고객이 기존 BOM·메모·RFQ를 Sales에 전달하는 것입니다. `#list`는 이 화면이며 `#sales`도 같은 화면으로 연결합니다. 메인·헤더·모바일 메뉴·사전의 견적 진입점을 맞춥니다.

기본 화면에는 회사·이메일·품목 입력을 요구하지 않습니다. 메인의 ‘Sales · 견적 문의’는 사이트 안의 `#list`로 연결하며 메일 앱을 자동으로 열지 않습니다. 기존 공개 견적 이메일 주소와 RFQ 이메일 예시를 바로 표시하고 주소·제목·본문 복사를 제공합니다. 고객은 원하는 메일 서비스에 붙여 넣고 기존 파일을 첨부합니다. 예시의 모든 항목을 채울 필요가 없으며 기존 BOM·요청서는 그대로 보내도 됩니다. 제목에 `[RFQ]`와 요청번호를 포함하므로 기존 메일 수집의 견적 분류와 연결됩니다. 카카오톡은 사진·짧은 문의의 보조 통로입니다. 복사를 접수나 실제 발송으로 표시하지 않습니다.

메모 작성과 표 분석·품목별 작성은 접힌 선택 도구입니다. 메모와 특수요건 확인 질문은 화면에 보이는 이메일 본문에 반영되고 복사·내려받기로 보존합니다. 본문 길이에 관계없이 내용을 임의로 줄이지 않으며 복사가 막혀도 표시된 전체 내용을 직접 선택하거나 파일로 내려받을 수 있습니다. 고객 메모는 메모리에만 남습니다. 선택 분석기는 사용자가 펼친 뒤에만 초기화합니다.

`v9_sales.js`가 문의 화면·메일 본문·복사·메모 내보내기를 맡습니다. `v7_ia.js`가 해당 화면으로 경로와 홈 연결을 제공하며 기존 BOM·C&D·제품 엔진은 그대로 사용합니다. 홈페이지 파일 업로드 서버나 자동 발송 API를 새로 만들지 않았습니다. 실제 이메일과 첨부 수신은 기존 네이버 수집 및 관리자 확인 절차를 따릅니다.
