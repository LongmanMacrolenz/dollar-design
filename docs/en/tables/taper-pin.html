About this item

A pin that aligns position with a 1:50 taper. It is driven into a reamed hole and knocked out from the large end, so it is used for fits that are disassembled many times.

Basis and limits of this table

  • Cross-checked against three or more manufacturer and distributor datasheets (not yet checked against the original standard)
  • Scope: Only the end convex height c max of the old DIN 1 (superseded by DIN EN 22339 and ISO 2339) — the end chamfer a of ISO 2339 is not included because only some nominal diameters (13 within 1–20 mm) agree in 3 or more sources, and the length range is not included either.
  • This is not a table from the original standard. Only the values and the standard number are arranged in Boltnote's own format.
  • Nominal sizes and columns that could not be confirmed are left out, not estimated.
  • For design, inspection and contracts, use the latest edition of the applicable standard and your drawing. Values can change when a standard is revised.
  • Checked 2026-10.
  • To cite this table: Boltnote Taper Pin dimension table, https://boltnote.net/en/tables/taper-pin, updated 2026-11-18. Give the basis line above with it.
