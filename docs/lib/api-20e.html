API Spec 20E

API규격

석유·가스 산업용 합금강·탄소강 볼팅

Alloy and Carbon Steel Bolting for Use in the Petroleum and Natural Gas Industries

사이트에서 이 항목 보기 ↗← 주제 목록으로
핵심구매 시 주의근거

석유·가스 장비(특히 해양·해저)용 합금강·탄소강 볼팅의 자격·생산·문서 요구 규격. 요구 수준을 BSL-1~3 세 단계로 나눕니다.

상태: 현행

핵심

  • 대상: 석유·가스 장비용 합금강·탄소강 볼팅(스터드·볼트·나사·너트 등)의 제조 자격, 생산, 문서화.
  • BSL-1(기본), BSL-2(중간), BSL-3(가장 엄격) 세 단계이며 숫자가 클수록 기술·품질·자격 요구가 늘어납니다.
  • 스테인리스·니켈합금 같은 내식 볼팅은 짝 규격 API Spec 20F(Corrosion Resistant Bolting)가 다룹니다.

BOM·구매 때 주의

  • 20E 적합은 완성품 검사만으로 붙일 수 있는 것이 아니라 20E 요구에 맞춘 제조 공정에서 나와야 합니다. 일반 A193 B7을 20E 제품으로 바꿔 부르지 않습니다.
  • BOM에 "API 20E"만 있고 BSL이 없으면 BSL 등급을 확인합니다.
  • 장비 규격이 요구하는 BSL과 재질 등급(예: B7·L7)을 함께 봅니다.

대응·대체 규격

  • API Spec 20F 내식 볼팅 (스테인리스·니켈합금)

근거: API Spec 20E · API Spec 20F · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
