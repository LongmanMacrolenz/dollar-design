DIN 913 ~ 916 (멈춤나사)

DIN규격폐지

육각구멍 멈춤나사 (무두볼트, 폐지된 DIN)

Hexagon socket set screws with flat point (913), cone point (914), dog point (915), cup point (916)

육각구멍 멈춤나사(무두볼트)의 옛 DIN 규격 네 가지. 각각 ISO 4026~4029의 수정판이었고, 폐지되어 해당 ISO로 넘어갔다.

상태: 폐지 (→ ISO 4026 ~ 4029)

핵심

  • DIN 913 평 끝 → ISO 4026, DIN 914 원뿔 끝 → ISO 4027, DIN 915 봉 끝 → ISO 4028, DIN 916 컵 끝 → ISO 4029.
  • 네 규격 모두 'ISO 수정판'으로 발행되었고 지금은 폐지로 표시된다(후속 DIN EN ISO 4026~4029).
  • 강 멈춤나사의 강도는 경도 기준 등급(45H 등)으로 표시한다.
  • 멈춤나사는 인장력을 받는 용도가 아니다.
  • 같은 종류의 국가 규격은 KS B 1028(6각 구멍붙이 멈춤 나사)과 JIS B 1177(六角穴付き止めねじ)이다.

BOM·구매 때 주의

  • 끝 모양이 없는 '무두볼트' 줄은 끝 모양을 정한다. 컵 끝이 가장 흔하다.
  • 45H 강 멈춤나사는 인장을 받지 않는 부품이라 ISO 4042(현행판)는 전기도금 뒤 베이킹을 요구하지 않는다. 도금 사양은 주문에 적는다.
  • 인치 멈춤나사(ASME B18.3)와 섞지 않는다.

대응·대체 규격

  • ISO 4026 ~ ISO 4029 끝 모양별 후속
  • KS B 1028 KS 6각 구멍붙이 멈춤 나사
  • JIS B 1177 일본 六角穴付き止めねじ

근거: DIN 913 · DIN 914 · DIN 915 · DIN 916 · ISO 4026 · ISO 4027 · ISO 4028 · ISO 4029 · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
