DIN 938 · 939 · 835 (스터드)

DIN규격

탭엔드 스터드 (박힘쪽 1d·1.25d·2d·2.5d)

Fasteners – Studs – Metal end ≈ 1d (DIN 938), ≈ 1,25d (DIN 939), ≈ 2d (DIN 835)

사이트에서 이 항목 보기 ↗← 주제 목록으로
핵심표·조건구매 시 주의근거

한쪽을 본체 탭 구멍에 박고 다른 쪽에 너트를 거는 스터드의 DIN 규격. 박힘쪽 길이로 번호가 나뉘며 모두 현행이고, ISO로 대체되지 않았다.

상태: 현행

핵심

  • 박힘쪽 나사 길이 bm: DIN 938 약 1d, DIN 939 약 1.25d, DIN 835 약 2d, DIN 940 약 2.5d.
  • 네 규격 모두 현행 DIN이며 제품 등급 A, 강 또는 스테인리스 제품을 다룬다.
  • DIN Media 요약에 DIN 938은 주로 강 모재용, DIN 940은 강도가 낮은 경금속용으로 적혀 있다.
  • 주문 길이 l은 박힘쪽을 뺀 너트쪽 길이다. 전체 길이는 l에 박힘쪽 길이를 더한 값이다.
  • 같은 종류의 국가 규격은 KS B 1037(스터드 볼트)과 JIS B 1173(植込みボルト)이다.

DIN Media 카탈로그 요약 기준 (현행판).

BOM·구매 때 주의

  • 박힘쪽 길이는 모재 재질과 탭 깊이로 정한다. 같은 호칭·같은 l이라도 DIN 번호가 다르면 전체 길이가 다르다.
  • '스터드볼트'만 적힌 BOM은 탭엔드 스터드인지 플랜지용 양너트 스터드(ASME B18.31.2·A193 B7)인지 가린다.
  • 펌프·밸브 압력부 스터드는 재질·성적서 요구(예: A193 B7)를 따로 확인한다.
