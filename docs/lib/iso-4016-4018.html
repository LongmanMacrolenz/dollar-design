ISO 4016 · ISO 4018 (등급 C)

ISO규격

육각볼트 반나사·온나사 — 제품 등급 C

Fasteners — Hexagon head bolts — Product grade C (ISO 4016) / Hexagon head screws — Product grade C (ISO 4018)

공차가 넓은 제품 등급 C의 육각볼트. ISO 4016은 반나사, ISO 4018은 온나사이며 보통나사 M5–M64입니다.

상태: 현행

핵심

  • ISO 4016 = 반나사, ISO 4018 = 온나사. 둘 다 보통나사 M5–M64, 제품 등급 C.
  • 제품 등급 C는 ISO 4759-1의 가장 넓은 공차입니다. 수나사 공차는 8g이고 강도 8.8 이상은 6g입니다 (등급 A·B는 6g).
  • 짝 부품의 기본 조합은 등급 C 너트 ISO 4034와 등급 C 평와셔 ISO 7091(100HV)입니다.
  • 강도 구분은 ISO 898-1에서 고릅니다. ISO 7091(100HV) 와셔는 6.8 이하 등급 C 볼트용으로 적혀 있고, ISO 898-3은 100HV를 5.8 이하에 권장하며 6.8은 접합 확인 조건부로 봅니다.
  • ISO 4016 현행판 변경: M7 추가, 머리 형상 허용 범위 추가, 최단·최장 표준 길이 규칙과 마킹 조항 신설.
  • 국내 KS B ISO 4034(6각 너트 - 제품등급 C)는 ISO 4034:1999 일치판입니다(KS 포털 표기).

BOM·구매 때 주의

  • 등급 C는 머리·몸통 치수 공차가 넓어 리머 구멍 같은 정밀 맞춤이나 기계 조립에 쓰지 않습니다.
  • 강도 구분 없이 'ISO 4016'만 적힌 줄은 강도를 되묻습니다.
  • DIN 601·558 표기 줄은 ISO 제품과 치수를 대조합니다.

대응·대체 규격

  • DIN 601 등급 C 반나사 볼트 (DIN EN 24016을 거쳐 ISO 4016으로 대체)
  • DIN 558 등급 C 온나사 볼트 (DIN EN 24018을 거쳐 ISO 4018로 대체)
  • KS B 1002 국내 6각 볼트 규격에 포함 (수정 부합)

근거: ISO 4016 · ISO 4018 · ISO 4759-1 · ISO 4034 · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
