KS ↔ ISO 대응 (KS B ISO 번호)

KS개념·설계

KS 체결 규격의 ISO 대응 수준

사이트에서 이 항목 보기 ↗← 주제 목록으로
핵심표·조건구매 시 주의근거

ISO를 그대로 옮긴(IDT) KS는 대개 'KS B ISO 번호'로, 국내 사정을 넣어 고친(MOD) KS는 고유 번호로 둔다. 포털에 대응 ISO와 부합화 수준이 표시된다.

핵심

  • 부합화 수준 표기: IDT(일치), MOD(수정, 부분 일치), NEQ(일치하지 않음).
  • KS B 1002(6각 볼트)는 ISO 4014~4018 MOD, KS B 1012(6각 너트)는 ISO 4032 계열 MOD이며, 둘 다 부속서 A를 둔다.
  • ISO 4017·4033·4035·10642·7089·7090·898-1·898-2·2338·8734·8752·1234 등은 KS B ISO 번호로 따로 있다.
  • KS B ISO 898-1은 ISO 898-1:1999, KS B ISO 898-2는 ISO 898-2:1992 기준으로 표시되어 ISO 현행판보다 오래되었다. 일본 JIS B 1051·B 1052-2는 각각 ISO 898-1:2013·ISO 898-2:2022를 그대로 옮겼다.
  • ISO 번호를 달지 않았지만 ISO와 일치(IDT)로 표시된 KS도 있다: KS B 0241(ISO 3506-1~3:1997), KS B 0238(ISO 4759-1·-3:2000), KS B 1067(ISO 7380:1983).
  • 포털의 부합화 칸이 '데이터 없음'인 KS B ISO 규격도 있다(예: KS B ISO 4017·2338·8734·8752).

국가표준인증 통합정보시스템(standard.go.kr) 상세 페이지 표시 기준. KS B 1003은 IDT·MOD가 함께 표시됨.

BOM·구매 때 주의

  • 'KS B 1002'와 'ISO 4014'는 같은 말이 아니다. MOD이고 부속서 A가 있어 2면폭을 확인한다.
  • KS B ISO 규격이 기준한 ISO 판이 오래된 경우가 있다. 성적서 판정에 쓸 판을 정한다.
  • KS 고유 강도 규격(KS B 0233 볼트, KS B 0234 너트 — 부속서에 4T~12T)과 ISO 898 계열 숫자 강도를 섞지 않는다.

근거: KS B 1002 · KS B 1012 · KS B 1003 · KS B ISO 898-1 · KS B ISO 898-2 · KS B 0241 · KS B 0238 · KS B 1067 · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
