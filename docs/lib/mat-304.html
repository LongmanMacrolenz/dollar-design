304 · 304L 스테인리스

공통재질

18-8 오스테나이트 스테인리스 304·304L

Type 304 / 304L Austenitic Stainless Steel (UNS S30400 / S30403)

사이트에서 이 항목 보기 ↗← 주제 목록으로
핵심구매 시 주의근거

Cr 약 18 %·Ni 약 8–10 %의 오스테나이트 스테인리스(18-8). UNS S30400·EN 1.4301·JIS SUS304가 서로 대응하고, 저탄소형 304L은 S30403·1.4307(또는 1.4306)·SUS304L입니다.

핵심

  • 대응 EN 1.4301(X5CrNi18-10): C 0.07 % 이하, Cr 17.0–19.5, Ni 8.0–10.5 %.
  • 304L(S30403): 저탄소형 — 대응 EN 1.4307은 C 0.030 % 이하이고, ISO 3506도 C 0.030 % 이하에 ‘L’ 표기를 허용.
  • 열처리로 경화하지 않고 냉간 가공으로 강도를 올림 — A193은 고용화 또는 고용화 후 가공경화 상태를 두고, ISO 3506은 A2-80을 가공경화품으로 둠.
  • 대응: JIS SUS304 / EN 1.4301(X5CrNi18-10), 304L은 SUS304L / 1.4307(X2CrNi18-9) — Ni가 조금 높은 1.4306도 304L 계열로 쓰임.

BOM·구매 때 주의

  • ‘SUS 볼트’만 적힌 BOM은 304인지 316인지, 강도 등급(B8 Class·A2-70)까지 확인.
  • 냉간 가공품은 자성을 띨 수 있음 — 자석으로 판정하지 않음.
