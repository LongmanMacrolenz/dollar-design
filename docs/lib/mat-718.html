Alloy 718 (UNS N07718) Precipitation-Hardening Nickel Alloy Bolting

UNS N07718 석출경화(시효경화) 니켈기 합금 718. ASTM A1014(고온용 볼팅)와 API 6A718(석유·가스 장비용)의 대상 합금입니다.

핵심

  • 고용화처리 후 시효로 Ni-Nb계 석출상(γ″)을 만들어 강도를 냄 — 고온에서도 강도를 오래 유지.
  • 볼팅 규격: ASTM A1014/A1014M (고온용 718 볼팅). 석유·가스 장비용 소재 규격은 API 6A718.
  • 봉재·단조재: ASTM B637 (고온용 석출경화 니켈합금)에 N07718 포함.
  • API 6A718은 ‘Nickel Base Alloy 718 (UNS N07718)’로 부르며, 흔히 상표명 Inconel(상표) 718로도 불림.

BOM·구매 때 주의

  • ‘인코넬 볼트’만 적힌 BOM은 합금 번호(625·718 등)와 열처리 상태를 확인.
  • 석유·가스 장비용 718은 API 6A718의 공정·미세조직 관리 요건을 사양서로 확인.
  • 성적서에 고용화·시효 조건과 경도가 있는지 확인.

근거: ASTM A1014/A1014M · API 6A718 · ASTM B637 · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
