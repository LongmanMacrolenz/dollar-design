양끝 스터드 (탭 엔드)

공통부품 용어

양끝 나사 스터드 (탭엔드·심는 볼트)

Double-End Stud / Tap-End Stud

가운데 나사 없는 몸통을 두고 양끝에 나사를 낸 스터드입니다. 한쪽을 본체 탭 구멍에 박는 탭엔드형은 DIN 938·939·835·940, KS B 1037, JIS B 1173, 인치는 ASME B18.31.2로 지정합니다.

핵심

  • DIN 탭엔드 스터드는 박힘쪽 나사 길이(bm)로 규격이 나뉩니다: DIN 938 ≈1d, DIN 939 ≈1.25d, DIN 835 ≈2d, DIN 940 ≈2.5d.
  • 박힘쪽 길이는 모재로 고릅니다: DIN 938(≈1d)은 주로 강, DIN 940(≈2.5d)은 강도가 낮은 경금속용입니다.
  • 인치 양끝 스터드는 ASME B18.31.2로, 양끝 나사 길이가 같은 형과 탭엔드가 다른 형이 있습니다. 탭엔드에 억지끼움 나사(ASME B1.12 Class 5)를 쓰기도 합니다.
  • 펌프 케이싱·베어링 하우징·씰 글랜드·밸브 본넷의 기본 체결부품으로 많이 씁니다.
  • KS 표준명은 KS B 1037 '스터드 볼트', JIS는 B 1173 '植込みボルト(심는 볼트)'입니다.

BOM·구매 때 주의

  • 주문 길이가 전장인지 박힘쪽을 뺀 길이인지 도면으로 확인합니다.
  • 박힘쪽과 너트쪽의 나사 공차가 다를 수 있습니다(인치 Class 5 억지끼움). 도면 표기를 그대로 받습니다.
  • '양나사볼트'는 전산 스터드와 양끝 스터드를 모두 부르는 말이라 몸통 유무와 양쪽 나사 길이를 확인합니다.
  • 본체 탭 나사가 상했으면 같은 호칭 스터드로 바꾸기 전에 나사 인서트 보수를 검토합니다.

대응·대체 규격

  • DIN 938 · 939 · 835 · 940 박힘쪽 ≈1d · 1.25d · 2d · 2.5d
  • KS B 1037 스터드 볼트
  • JIS B 1173 植込みボルト
  • ASME B18.31.2 인치 double-end stud

근거: DIN 938 · DIN 939 · DIN 835 · DIN 940 · KS B 1037 · JIS B 1173 · ASME B18.31.2 · ASME B1.12 · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
