작은나사·태핑나사 (피스·머신스크류)

Machine Screw / Tapping Screw

사이트에서 이 항목 보기 ↗← 주제 목록으로
핵심구매 시 주의근거

머리에 십자·일자 홈이 있는 작은 지름 나사입니다. 미터 나사산의 작은나사(ISO 7045·7046, KS B 1023, 인치 ASME B18.6.3)와 스스로 나사산을 내는 태핑나사(ISO 7049~7051, 직결피스 ISO 15480 등)로 나뉩니다.

핵심

  • 현장의 '피스'는 작은나사·태핑나사·직결피스를 두루 부르는 말이라 나사 종류부터 확인합니다.
  • 작은나사는 미터 나사로 너트·탭 구멍에 체결합니다: +자 냄비머리 ISO 7045(DIN 7985), +자 접시머리 ISO 7046(DIN 965), +자 둥근접시머리 ISO 7047(DIN 966), 일자 홈 ISO 1207·1580·2009·2010.
  • 태핑나사는 ST 나사(ISO 1478, 예: ST4.2)로 얇은 판·수지에 스스로 나사산을 냅니다: +자 냄비 ISO 7049, 접시 ISO 7050, 둥근접시 ISO 7051, 육각 ISO 1479.
  • 직결피스(셀프드릴링 나사)는 끝에 드릴이 있어 아래 구멍 없이 강판에 박습니다 (ISO 15480 등, 구 DIN 7504).
  • 냄비·트러스머리는 머리 밑면부터, 접시머리는 머리 윗면부터(전장) 길이를 잽니다.
  • 십자 홈은 H형과 Z형이 있어 맞는 드라이버가 다릅니다 (ISO 4757).
  • 인치 작은나사는 ASME B18.6.3(Machine Screws and Machine Screw Nuts)으로 지정하며, 같은 #10이라도 UNC·UNF 산 수가 달라 산 수를 함께 적습니다.
  • 작은나사는 머리에 등급 표시가 없는 경우가 많아 재질(강·18-8·316)과 표면처리를 줄에 적습니다.

BOM·구매 때 주의

  • '피스 M4×10'은 작은나사, '피스 4×16'은 태핑나사(ST4.2)일 수 있어 나사산 종류를 확인합니다.
  • 직결피스는 판 두께 합이 드릴 끝 길이보다 두꺼우면 쓸 수 없습니다.
  • 트러스·바인드머리는 ISO 작은나사 규격에 없는 머리라 도면이 따르는 규격(KS·JIS 또는 ASME B18.6.3)의 형상으로 확인합니다.
  • 100° 접시머리 나사(항공 규격 등에 흔함)는 90°(미터)·82°(인치) 접시 자리와 맞지 않습니다.

근거: ISO 7045 · ISO 7046 · ISO 7047 · ISO 1207 · ISO 1580 · ISO 2009 · ISO 2010 · ISO 7049 · ISO 7050 · ISO 7051 · ISO 1478 · ISO 1479 · ISO 4757 · ISO 15480 · DIN 7504 · KS B 1023 · ASME B18.6.3 · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
