무두볼트 (육각 구멍붙이 멈춤나사)

Hexagon Socket Set Screw

머리 없이 육각 구멍만 있는 나사로, 끝으로 축을 눌러 풀리·커플링을 고정합니다. 미터는 끝 모양별 ISO 4026~4029(DIN 913~916), 인치는 ASME B18.3 + ASTM F912로 지정합니다.

핵심

  • 끝 모양마다 규격 번호가 다릅니다 (아래 표). 끝 모양이 없는 줄은 컵 끝으로 보는 것이 유통 관행입니다.
  • 길이는 끝에서 끝까지 전장으로 잽니다.
  • 강 멈춤나사의 강도는 인장강도가 아니라 경도 등급(ISO 898-5, 예: 45H)으로, 스테인리스는 ISO 3506-3 등급(예: A2-21H·A4-21H)으로 표시합니다.
  • 멈춤나사는 인장 하중을 받는 용도가 아닙니다.
  • 인치 스테인리스 ASTM F880은 소켓 멈춤나사 0.060–1.000"(F880-24)이고, 합금강은 ASTM F912로 지정합니다.
  • KS B 1028(6각 구멍붙이 멈춤나사)·JIS B 1177이 같은 계열의 국가 규격입니다.

BOM·구매 때 주의

  • '무두볼트 M8×10'처럼 끝 모양이 없으면 되묻습니다. 컵 끝으로 볼 때는 그렇게 적어 확인받습니다.
  • 45H 강 멈춤나사는 인장 하중을 받지 않는 부품이라 ISO 4042:2022는 전기도금 뒤 베이킹을 요구하지 않습니다. 도금 사양은 주문에 적습니다.
  • 같은 산 수라도 UNC(60°)와 위트 나사(55°)는 나사산 각도가 달라 맞지 않습니다.
  • 나일론 패치·소프트 팁·사각머리·일자 홈 멈춤나사는 별도 품목이라 사양을 따로 받습니다.
  • 봉 끝은 컵·평 끝보다 최단 길이가 깁니다.
