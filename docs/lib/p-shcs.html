렌치볼트 (육각 구멍붙이 볼트)

Hexagon Socket Head Cap Screw

원통 머리에 육각 구멍이 있는 볼트입니다. 미터 ISO 4762(DIN 912, KS B 1003, JIS B 1176), 인치 ASME B18.3 + ASTM A574(합금강)·F837(스테인리스)로 지정합니다.

핵심

  • 길이 L은 머리 밑면부터 끝까지 잽니다.
  • 미터 강도 구분은 8.8·10.9·12.9이고, ISO 4762:1997 표 2는 12.9의 나사 공차를 5g6g, 나머지를 6g로 둡니다.
  • ASME B18.3에는 옛 1936 시리즈 렌치볼트 치수가 별도 부록으로 남아 있어, 옛 도면의 1936 시리즈는 현행 치수와 구분해 확인합니다.

BOM·구매 때 주의

  • 12.9 전기아연도금은 수소취성 위험이 커서 흑착색이 기본입니다. 도금이 필요하면 베이킹 조건을 성적서로 확인하거나 아연 플레이크로 바꿉니다.
  • 인치 BOM의 'CAP SCREW'만으로는 hex cap screw(육각머리)인지 socket head cap screw(렌치볼트)인지 알 수 없어 되묻습니다.
  • 사워 서비스(NACE MR0175/ISO 15156) 요구가 있는 줄은 고강도 렌치볼트(A574·12.9)의 경도 적합성을 먼저 확인합니다.
  • M14는 ISO 4762에서 비우선(괄호) 호칭이고, M18·M22는 ISO 4762 표에 없습니다.

대응·대체 규격

  • ISO 4762 기준 규격
  • DIN 912 ISO 4762로 대체 (DIN Media)
  • KS B 1003 6각 구멍붙이 볼트 (ISO 4762:1997 대응, KS 포털)
  • JIS B 1176 六角穴付きボルト
  • ASME B18.3 + ASTM A574 인치 합금강 (스테인리스 F837)
