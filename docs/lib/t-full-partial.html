온나사 vs 반나사

공통개념·설계

온나사(전나사)와 반나사

Fully threaded vs partially threaded bolts

온나사(ISO 4017·DIN 933)는 머리 아래까지 나사, 반나사(ISO 4014·DIN 931)는 나사 길이 b만 깎고 나머지는 몸통이다. 전단·피로·물림 위치가 달라 바꿔 쓸 때 확인한다.

핵심

  • ISO 4014 나사 길이 b (참고값): L ≤ 125 mm면 2d + 6, 125 < L ≤ 200이면 2d + 12, L > 200이면 2d + 25. 예: M16 × 100 → b = 38 mm.
  • 전단면에 몸통이 오면 몸통 단면적으로 버텨 나사부보다 강하다. 철골 설계도 전단면에 나사가 있는지(N)·없는지(X)로 강도를 나눈다.
  • 반나사의 몸통은 늘어나는 길이가 길어 예압 유지·피로에 유리하다. 감경 몸통 볼트는 이 효과를 더 키운 것이다.
  • ISO 4014는 지름별 최소 길이가 있어(예: M16은 65 mm), 그보다 짧으면 ISO 4017 온나사를 쓴다 (ISO 4014:2022).

BOM·구매 때 주의

  • 전단 연결 볼트를 온나사로 바꾸면 전단면에 나사가 걸려 강도가 떨어진다.
  • 반나사 볼트를 길이만 줄여 바꾸면 나사부가 판 속에 묻혀 너트를 끝까지 조일 수 없는 일이 생긴다. 그립 길이와 b를 함께 본다.
  • BOM에 온나사·반나사 구분이 없으면 원하지 않는 형태가 올 수 있다. ISO 4014/4017 (DIN 931/933) 번호로 구분해 적는다.

근거: ISO 4014 · ISO 4017 · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
