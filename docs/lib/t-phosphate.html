인산염 피막 (아연·망간 인산염)

Phosphate conversion coating (zinc / manganese phosphate)

사이트에서 이 항목 보기 ↗← 주제 목록으로
핵심구매 시 주의근거

강 표면에 아연·망간 인산염 결정층을 만들어 기름·왁스를 잡아 두는 화성 피막입니다. 단독 내식성은 약하지만 윤활·도장 바탕과 마찰 안정에 쓰고, 처리 중 수소가 들어갈 수 있습니다.

핵심

  • 아연 인산염은 도장·윤활 바탕으로, 망간 인산염은 기름을 잘 머금어 마모·눌어붙음 방지에 많이 씁니다.
  • 색은 회색~흑회색이며 인산염 + 방청유 상태로 공급되는 경우가 많습니다.
  • 산성 용액 공정이라 고경도 부품은 수소가 들어갈 수 있어, 필요하면 처리 뒤 수소 제거 처리를 합니다.
  • ISO 10683은 아연 플레이크 전처리로 인산염을 허용합니다. 플레이크 경화 중에 수소가 빠져나가기 때문입니다.
  • 피막과 기름 상태에 따라 마찰계수가 달라 토크-체결력 관계가 바뀝니다.
  • 관련 규격 예: ISO 9717, MIL-DTL-16232.

BOM·구매 때 주의

  • 인산염 + 방청유는 옥외 장기 방청용이 아닙니다. 보관 중 기름이 마르면 녹이 납니다.
  • 고경도 볼트·스프링 부품에 인산염을 지정하면 수소 제거 조건을 확인합니다.
  • PTFE 코팅의 바탕으로 인산염을 쓰는 경우가 있어, 코팅 사양서에 전처리를 적습니다.

ISO 공식 검색·안내 ↗

근거: ISO 9717 · MIL-DTL-16232 · ISO 10683 · 라이브러리 일괄 검토 2026-10 (개별 항목 검토일 미기록). 프로젝트 판본·허용차·사용 조건은 규격 원문과 공급처 서류로 확인해야 합니다. 미확인 값은 추정하지 마세요.
