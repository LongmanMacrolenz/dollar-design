RF · RTJ 면 형식과 스터드 길이

ASME개념·설계

플랜지 면 형식(RF·RTJ)과 스터드 길이

Raised face (RF) vs ring type joint (RTJ) flange facings and stud length

RF는 돌출된 면에 개스킷을 끼우고, RTJ는 홈에 금속 링(ASME B16.20의 R·RX·BX형)을 끼운다. 링 번호와 스터드 길이는 적용 플랜지 규격 표로 확인한다.

핵심

  • RTJ 링은 R·RX·BX 형식이 있고, 형식마다 맞는 배관 호칭이 표로 정해진다 (ASME B16.20).
  • RF 돌출 높이: Class 150·300은 1/16"(환산 1.6 mm), Class 600은 1/4"(환산 6.4 mm).
  • ASME 해석 B16.5-18-07(B16.5-2009 대상): B16.5는 RF 높이 공차를 두지 않는다.
  • 같은 Class·NPS에서 RTJ 스터드가 RF보다 긴 경우가 많다. 예: Class 150 NPS 8은 RF 4-1/4", RTJ 4-3/4".
  • Class 150 NPS 1/2·3/4는 공개 차트에 RTJ 스터드 길이가 없다.
  • ASME 해석 2-34(B16.1-1989·B16.5-1988 대상): RF 플랜지를 평면(FF) 플랜지에 볼팅하는 것을 금지하지 않는다.

BOM·구매 때 주의

  • RTJ 플랜지를 RF 길이로 사면 너트 물림이 모자란다. BOM에 면 형식을 적는다.
  • RTJ 링은 형식(R·RX·BX)과 번호까지 맞아야 한다. 볼트 BOM과 링 BOM을 함께 확인한다.
  • RF 높이가 다른 플랜지(1/16"와 1/4")를 맞붙이면 표 길이가 맞지 않는다. 길이를 다시 계산한다.
  • RF와 FF를 맞붙이는 조인트(주철·비금속 플랜지 등)는 개스킷 형식과 볼트 조임 조건을 따로 검토한다.

근거: ASME B16.5 · ASME B16.20 · ASME B16.5 해석 2-34·B16.5-18-07 · 제조·유통사 공개 기술자료 3곳 이상 대조 (규격서 원문 대조 전) · 확인 2026-10. 규격 원문을 옮긴 것이 아니라 요점을 정리한 것입니다.
