유효단면적 (응력 단면적)

공통개념·설계

나사의 응력 단면적 As

Tensile stress area of threaded fasteners (As)

사이트에서 이 항목 보기 ↗← 주제 목록으로
핵심표·조건구매 시 주의근거

나사부 인장 강도를 계산할 때 쓰는 단면적. 인치는 As = 0.7854(D − 0.9743/n)² in², 미터는 As = 0.7854(d − 0.9382P)² mm². 보증하중·예압 응력 계산의 기준이다.

핵심

  • 인치(NIST H28 부록 A5): As = 0.7854 × (D − 0.9743/n)² [in²], D = 호칭 지름(in), n = TPI.
  • 미터(ISO 898-1): As = (π/4) × ((d2 + d3)/2)², d2 = d − 0.6495P, d3 = d − 1.2269P → As ≈ 0.7854 × (d − 0.9382P)² [mm²].
  • 예: 3/4"-10 UNC → 0.750 − 0.0974 = 0.6526 → As = 0.7854 × 0.6526² = 0.334 in² (약 215 mm²).
  • 예: M16×2 → 16 − 1.876 = 14.124 → As = 0.7854 × 14.124² = 157 mm².
  • 예: 3/4" 몸통 0.442 in² vs As 0.334 in²(약 24% 작음), M16 몸통 201 mm² vs As 157 mm²(약 22% 작음). 지름이 작고 피치가 굵을수록 차이가 커진다 (1/4"-20은 약 35%).
  • 보증하중 = As × 보증응력, 최소 파단하중 = As × 최소 인장강도, 볼트 응력 = 예압 / As.
  • 압력용기 플랜지 설계(ASME BPVC Section VIII Div.1 부록 2)는 As가 아니라 골지름 단면적(root area)을 쓴다. 같은 볼트도 계산서마다 단면적 기준이 다를 수 있다.

BOM·구매 때 주의

  • 하중 계산서가 응력 단면적, 골 단면적, 몸통 단면적 중 무엇을 썼는지 확인한다. 토크표도 기준 단면적이 다르면 수치가 달라진다.
  • UNC를 8UN으로 바꾸면 As가 커진다 (1-1/8"에서 0.763 → 0.790 in²). 같은 응력 목표라도 토크·예압 표를 나사 계열에 맞춰 쓴다.
  • 감경 몸통(허리 가는) 볼트는 몸통이 As보다 작을 수 있어 최소 단면 기준으로 본다.
