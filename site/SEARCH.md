# 검색용 페이지 관리

홈과 제품·라이브러리 문서는 자바스크립트 실행 전에도 본문을 제공합니다.
제품 구매 안내는 기존 공개 카탈로그의 품목·표기·주의사항으로 만들며,
재고나 판매 가격을 확정하는 페이지가 아닙니다.

- `catalog.py`: 공개 카탈로그 읽기, 공통 주소·홈 메타정보, 설명문 80자 이내 발췌.
- `product-paths.json`: 카탈로그 ID → 고정 주소. 이름 변경 시에도 주소를 유지합니다.
  새 품목을 추가하면 중복되지 않는 경로를 함께 넣습니다. 경로를 바꿔야 하면
  기존 주소의 영구 리디렉션과 사이트맵·링크 변경을 같은 작업에 포함합니다.
- `build_products.py`: 제품별 구매 안내와 제품군·전체 목록.
- `build_lib.py`: 라이브러리 문서, 전체 사이트맵과 robots.txt.
- `build.py`: 홈 메타정보와 초기 제품 소개. 앱이 로드되면 같은 컨테이너를
  기존 홈페이지 화면으로 교체합니다. 방문자에게 숨긴 검색 전용 본문을 넣지 않습니다.

`python3 tools/build_all.py`로 결과물을 만들고 `python3 tools/check.py`를
통과시킵니다. `tools/check_search.py`는 모든 검색 문서의 제목·설명·표준 주소,
사이트맵 일치와 내부 링크·제품 목록 범위를 확인합니다.

검색엔진 등록 주소는 `https://boltnote.boltnote.workers.dev/`입니다.
`#home` 같은 화면 식별자는 개별 검색 문서 주소가 아닙니다.
Google·네이버에 제출할 사이트맵은 `/sitemap.xml` 하나입니다.
소유 확인 파일은 계속 보관합니다. 페이지를 추가했다고 수집·노출·순위가
확정되는 것은 아니며, 실제 검색어·노출·클릭과 색인 상태는 각 콘솔에서 확인합니다.

공개 본문은 한국어 제품명, 영문 BOM 표기, 적용 규격을 자연스럽게 연결합니다.
키워드 나열, 지역만 바꾼 중복 페이지, 확인되지 않은 공급·서류 약속,
가격·리뷰·재고를 지어낸 구조화 데이터를 추가하지 않습니다.
