# 엔지니어 노트 쓰는 법 (대표 요청 2026-11-26)

`site/notes/<slug>.md` 한 파일이 글 하나입니다. `python3 tools/build_all.py`가 `docs/notes/`와 사이트맵·llms.txt에 반영합니다. 생성기는 `site/build_notes.py`.

## 규칙

- **영문 짝이 꼭 있어야 합니다.** 한국어 글마다 `site/notes/en/<같은 slug>.md`를 같은 머리(date·lib)로 만듭니다. 한국어 글을 옮긴 번역이며 수치·사실을 더하지 않습니다. 영문 짝이 없으면 빌드가 멈춥니다. 영문 제목은 검색어(예: "A193 B7 ...")가 앞에 오게, desc는 160자 이하.

- 글쓴이는 대표 박세중(기계엔지니어)입니다. 말투는 사이트 글 규칙(AGENTS.md 3번)과 같이 `~ㅂ니다`, 짧고 담백하게.
- **수치·요건은 `site/lib.json` 항목에 이미 출처와 함께 있는 것만** 씁니다. 머리의 `lib:`에 근거 항목 id를 적으면 글 끝에 링크와 근거 문서가 붙습니다. 항목에 없는 값은 쓰지 않습니다(AGENTS.md 4번). 새 값이 필요하면 글을 쓰지 말고 그 주제를 건너뜁니다.
- 고객·회사·공급처·제조사 이름, 대표의 직장, 재고·가격·납기 약속, 후기·통계를 쓰지 않습니다.
- 규격 원문 문장을 옮기지 않습니다. 실무에서 읽는 순서(무엇을 되묻나, 견적서와 C&D 리스트에 어떻게 나눠 적나)로 씁니다.
- 제목은 검색어가 앞에 오게(예: "A193 B7 ..."), 설명(desc)은 80자 이하.
- 분량은 소제목 4~6개, 화면 두세 장. 끝에 "정리" 목록 세 줄.

## 머리 예시

```
---
title: 제목
desc: 80자 이하 설명
date: 2026-12-01
lib: gr-b7, astm-a193
---
```
